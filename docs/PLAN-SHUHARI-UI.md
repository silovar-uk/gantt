作成日: 2026-09-21 / 対象: `silovar-uk/gantt`(https://silovar-uk.github.io/gantt/)
調査時点の `origin/main`: `597f265` / 実装担当: Sonnet

## 結論

いまの画面は整っていますが、**時間が見えていません**。
ガントは時間の絵のはずなのに、描かれているのは「表の横に並んだ淡い箱」です。
今日はどこか、何が遅れているか、次の締切まで何日か、さっき何が動いたか。どれも画面から読み取れません。

本計画は、見た目の洗練を入口にして、**時間そのものを画面に描きます**。芯は一文です。

> **時間が、見える。**

守破離は、ガントという型(かた)の扱い方として通します。

| 段 | 型への態度 | 三つの手 |
|---|---|---|
| 守 | 型を守る。誰が見てもガントと分かり、迷わない | 画面を使い切る / 文字と余白の型 / 二段の日付見出し |
| 破 | 型を破る。慣習より、速さと見通しを取る | 日の格子を消す / 操作盤を下に浮かべる / 名前をバーの上へ |
| 離 | 型を離れる。このアプリにしか無いもので、状況を語る | いまの刃と遅れの糸 / 変化の残像 / 地平線 |

驚きは足しません。**便利さの副作用として起こします。**
開いた瞬間に遅れが目に入る。AIから戻した瞬間に、動いた予定が残像で分かる。`Ctrl+K` と数文字で、どの予定にも着く。
驚く理由が、どれも「速くなった」ことにあるようにします。

範囲は4段です。停止点は第2段の見た目確認の1回だけです。

| 段 | 内容 | 得られるもの |
|---|---|---|
| 1 | 型を整え、いまを描く(U1〜U9) | 画面の余白が消え、遅れと締切が一目で分かる |
| 2 | 道具を手元へ(U10〜U16) | 題字・地平線・浮かぶ操作盤・`Ctrl+K`・全幅の一覧・スマホの札。**ここで1回停止** |
| 3 | 変化は残像で語る(U17〜U19) | 取り込み・Undo・ドラッグで、何が動いたかが見える。完了印が消えない |
| 4 | 仕上げ(U20〜U21) | Presentの題字と凡例、動きの型、README |

前段として U0(e2eを手元で回せるようにする)を先に行います。

## 思想

### 芯

> **時間が、見える。**

ガントの価値は「いつ・何が・どれくらい」を一枚で見せることです。
いまの画面は「何が」は見せていますが、「いつ」の意味(過去・いま・締切・変化)を描いていません。
描くべきものは4つです。**いま、遅れ、締切、変化。** そして、それらを邪魔しない静かな地です。

### 三つの原則

**1. 図が主役、道具は手元に**

操作ボタンは図の上に居座りません。題字の帯は1行、地平線は1行、操作盤は下に浮かびます。
図は画面の端から端まで使います。一覧・ガント・スマホのどの表示でも、空白を残しません。

**2. いまを基準に描く**

すべての予定は「いま」との関係で見た目が決まります。
過ぎた時間は濃く、これからの時間は淡く。遅れは今日まで朱の糸を引き、締切は柱として立ちます。
色は増やしません。いまを表す色は朱(`#C93C22`)の1色だけです。

**3. 変化は、残像で語る**

予定が動いたら、前の姿を点線で一瞬残します。AIから戻した予定は、確認が済むまで残します。
「何が変わったか」を、トーストの文章ではなく図で伝えます。

### 驚きの作法

- 驚きは、便利さの副作用として起こします。情報を運ばない動きは入れません。
- 動きは初回か、変化が起きた瞬間だけです。常に動いているものを置きません。
- `prefers-reduced-motion: reduce` では、すべての動きを止めます。止めても情報は残ります。

### 何を足さないか

- 依存パッケージ、ビルド、フレームワーク、Webフォント。
- ダークモード(トークンが揃えば後から足せます。今回は検証面が倍になるため入れません)。
- 新しいモード(初心者/上級者)。守破離をモード切替として実装しません。
- 依存関係・クリティカルパス。別の製品の話です。
- 純増するファイルは3本だけです: `assets/v15-now-desk.css`、`src/v5/classic/22-command-palette.js`、`src/v5/classic/23-afterimage.js`。
- 散らばったツールバーの規則(6ファイル)は削除し、1ファイルにまとめます(U12)。

## 守破離の設計

### ガントの「型」とは何か

守破離を語るには、まず守るべき型を決める必要があります。ガントの型は次の9つです。

| 型 | 本計画での扱い |
|---|---|
| 時間は左から右へ流れる | 守 |
| 予定名は行に揃う(左の列) | 守。ただし表ではなく「索引」にする |
| 期間は棒、節目はひし形 | 守 |
| 色はカテゴリー | 守。色の数は増やさない |
| 日付の見出しは二段(月/日) | 守。いまは「9/28」形式の一段で、月の境目が見えない |
| 日ごとの格子 | 破。週末の帯と月の罫だけにする |
| 操作は上のツールバー | 破。下に浮かぶ操作盤と `Ctrl+K` |
| 今日は一本の線 | 離。刃にして、遅れの糸・締切の柱と組ませる |
| 画面は変化を覚えていない | 離。残像で前の姿を見せる |

### 三段 × 三手

| 段 | 手 | 何が良くなるか |
|---|---|---|
| 守 | **画面を使い切る**(U2) | 一覧65%・ガント24%・下170pxの空白が消える |
| 守 | **文字と余白の型**(U1) | 見出し・補助の文字が11px以上になる(目盛りの数字だけ10.5px)。数字は等幅 |
| 守 | **二段の日付見出し**(U3) | 月の境目が、線と見出しで分かる |
| 破 | **日の格子を消す**(U3) | 縦の線が8割減り、バーと今日が浮かぶ |
| 破 | **操作盤を下に浮かべる**(U12) | 上部が124px→92px。スマホは178px→92px |
| 破 | **名前をバーの上へ**(U4, U5, U9) | 日付がホバー無しで読める。節目に名前が付く |
| 離 | **いまの刃と遅れの糸**(U6, U7, U8) | 遅れの件数・日数、締切までの日数が一目で分かる |
| 離 | **変化の残像**(U17〜U19) | 取り込み・Undo・ドラッグで、動いた予定と日数が分かる |
| 離 | **地平線**(U11) | プロジェクト全体の山場(忙しい時期)が稜線で見える |

守破離を層にはしません。前回までと同じく、**一つの部品が三段を持ち、切替無しで行き来できる**形にします。

### 部品ごとの適用

| 部品 | 守 | 破 | 離 |
|---|---|---|---|
| バー | 色と位置で読む | 名前と日付がバーの中(入らなければ外) | 過ぎた時間だけ濃くなる。遅れは朱の糸を引く |
| 今日 | 縦の線がある | 見出しに「今日 9/21 月」の旗 | 旗に「遅れ 2」。押すと遅れだけになる |
| 締切 | ひし形 | 朱のひし形 | 全行を貫く点線の柱と「あと52日」 |
| 左の列 | 名前が行に揃う | 表をやめて索引(色の縁・丸い完了・状態) | 遅れは「4日遅れ」と朱で出る |
| 時間の窓 | 全体と表示範囲 | 独立した1行に出す | 忙しさの稜線、過去の地、朱の今日 |
| 操作 | ボタンがある | 下に浮かぶ操作盤 | `Ctrl+K` の手帳で、予定にも操作にも着く |
| 変化 | トーストで知らせる | トーストに移動量 | 残像と「+4日」の付箋。「変更だけ表示」 |

## 驚きの設計(すべて便利さとの対)

| 瞬間 | 起きること | 便利さ |
|---|---|---|
| 開いた瞬間 | 今日の線が上から引かれ、遅れの糸が今日まで伸びる(0.5秒、初回のみ) | 最初に目が行くのが「遅れ」になる |
| AIから戻した瞬間 | 動いた予定に前の姿の点線と「+4日」、新しい予定に「新規」。下に「移動3・追加1・削除1」 | 変更点の確認が、全件の目視から数件の確認になる |
| `Ctrl+K` | 手帳が落ちてきて、「発表」と打てば予定も操作も出る | 数文字でどの予定にも着き、カードまで開く |
| ドラッグ | 元の位置に点線が残り、離すと残像が消えていく | 置く前と後が同じ画面で比べられる |
| 地平線を見る | プロジェクトの稜線と朱の今日 | 山場がいつか、いまが山の手前か後かが分かる |
| Present | 題字と凡例だけが残り、図が画面いっぱいに広がる | 会議でそのまま見せられる |

## 作戦

### 前提

- 最新の `origin/main` から `feat/shuhari-ui` を作ります。
- 不具合と見た目は、持ち主のファイルを直接直します。レイヤーを積み増しません。
- 新規ファイルは3本です。関心事が独立しているため分けます。
  - `assets/v15-now-desk.css`: いまの刃・遅れの糸・締切の柱・残像・浮かぶ操作盤・条件の帯・手帳の見た目。先頭コメントに `now desk owner`。
  - `src/v5/classic/22-command-palette.js`: `Ctrl+K` の手帳。
  - `src/v5/classic/23-afterimage.js`: 残像と取り込みの差分。
- `validate-css-architecture.mjs` は孤児ファイルを禁止しています。新規3本は `index.html` への追加が必須です。
- `index.html` の `?v=` を変えたら、`public-smoke.yml` と `validate-v5.yml` の照合値を**同じコミットで**更新します。
- JS内部の版数定数(`COMPASS_VERSION`、`DENSITY_VERSION`、`POLISH_VERSION`、`MACRO_VERSION` など)は**変えません**。CIとe2eが値そのものを照合しています。変えるのは `?v=` だけです。

### 段階と停止点

| 段 | 対象仕様 | 停止 |
|---|---|---|
| 0 | U0(e2eを手元で回す) | なし |
| 1 | U1〜U9(型を整え、いまを描く) | なし |
| 2 | U10〜U16(道具を手元へ) | **ここで1回停止。スクリーンショットをモックと並べて承認** |
| 3 | U17〜U19(残像・差分・引き継ぎ) | なし |
| 4 | U20〜U21(仕上げ) | なし |

第2段で止めるのは、第1段と第2段で「見た目の型」が揃うからです。第3段以降は振る舞いの追加です。
承認後は、push、PR作成、CI確認、squashマージ、`deploy-pages` と `public-smoke` の成功確認、公開URLでの再確認まで止めずに進めます。

## 仕様

### U0. e2eを手元で回せるようにする

公開後にしかe2eが走らない仕組みのまま大きな見た目の変更を入れると、壊れた状態が公開されます。先に手元で回せるようにします。

## 要求の解釈と判断

### 「自分を置き去りにするぐらい、びっくりのかっこいいUI」

二通りに読めます。

| 読み方 | 内容 | 本計画 |
|---|---|---|
| 見た目の衝撃 | 暗い背景、光る線、常に動く演出 | 採らない。便利さ＞楽しさに反し、毎日の作業で疲れる |
| **アプリが先に知っている(採用)** | 開けば遅れが、戻せば変化が、打てば予定が、先に出てくる | U6〜U8、U14、U17〜U18 |

かっこよさは、余白と文字の規律(守)と、朱の1色(離)で出します。モックで確かめてください。

### 配色

セージの手の色(2026-09-14の決定)は守ります。足すのは「いま」を表す朱だけです。
全面的な配色変更(墨の帯、紺など)も考えましたが、e2eの照合値と決定済みの型を崩す割に、便利さが増えません。

### 入れ替えで完了印を引き継ぐ(U19)

入れ替えの意味が「すべて捨てて入れる」から「同じ名前の予定は印を残して入れる」に少し変わります。
AIとの往復で完了印が消えるのは、利用者が望む結果ではないと判断し、引き継ぎを既定にします。
引き継ぎたくない場面があれば、承認時に言ってください。U19を外すだけで、U18の差分表示はそのまま残せます。

### 行の高さの既定を36pxへ(U2)

少ない件数で行が24pxに留まり、下に空白が残る問題を直します。手で行を詰めていた人も、移行時に一度36pxへ戻ります。つまみですぐ戻せます。
