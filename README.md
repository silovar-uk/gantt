# Gantt Desk

外部AIで整形したJSONを取り込み、確認・編集・可視化するためのローカル保存型ガントチャートです。サーバーもAI APIキーも使いません。

公開URL: https://silovar-uk.github.io/gantt/

## 特徴

- 入れた予定は、表示期間の外にあっても取り込み直後に自動で全体表示へ合わせます
- ブラウザ内のローカル保存（IndexedDB、フォールバックで`localStorage`）
- AI機能・APIキー・サーバー処理なし。ChatGPTへの受け渡しはブラウザのタブを開くだけです
- JSONの貼り付けによる取り込み。反映前に検証・プレビューできます
- 反映方法は「予定を追加」「予定をすべて入れ替え」の2択（バックアップ形式のみ「プロジェクトを復元」も選べます）
- 完全バックアップJSON、TSV、XLSX、AI用JSONの書き出し
- タスクバーのドラッグ移動、右端ドラッグによる期間変更
- 一覧の行内編集（予定名・日付）、予定カードでのその場編集、詳細モーダルからの編集・削除
- Undo / Redo、削除やカテゴリ変更もトーストの「元に戻す」から戻せます

## 表示モード

デスクトップは上部ツールバーで **一覧 / 分割 / ガント** を切り替えられます。スマホ幅（767px以下）では **一覧 / ガント** の2択です。

- 分割モード：一覧とガントチャートを左右に並べて表示（デスクトップ・タブレットの既定）
- 一覧モードとガントモードは、必要な情報だけに絞って表示します

## 時間が見える画面

画面は「いま」を基準に描かれます。色の使い分けは、手の色(セージ)が操作・選択、朱がいま・遅れ・締切です。

- **いまの刃**: 今日線は朱で、見出しに `今日 9/21 月` の旗が付きます。今日より前の時間は少し沈み、バーは過ぎた時間だけ濃くなります
- **遅れの糸**: 終了日が過ぎて未完了の予定は、バーの終わりから今日線まで朱の糸を引き、`4日遅れ` と出ます。旗の `遅れ 2` を押すと、遅れだけに絞れます
- **締切の柱**: 「締切として表示」にしたマイルストーンは全行を貫く点線の柱になり、見出しに `締切 発表会 · あと52日` の旗が出ます。題字の帯にも次の締切までの日数が出ます
- **残像**: ドラッグ・Undo・Alt+矢印で予定が動くと、前の位置が点線で残り、`+3日` の付箋が出ます
- **地平線**: 題字の帯のすぐ下の1行に、プロジェクト全体の忙しさの稜線と今日(朱)が出ます(下の「時間の窓」)
- **浮かぶ操作盤**: 予定の追加・検索・絞り込み・表示の切り替えは、画面の下に浮かぶ操作盤にあります。図は画面いっぱいに広がります

## 時間の窓（Time Window）

ヘッダー下の細い帯が、プロジェクト全体の中でいま見ている期間を示します。

- 窓の端をドラッグして期間を伸縮（ズーム）
- 窓の中をドラッグ、または窓の外をクリックしてパン（期間移動）
- 窓の上でホイール操作するとカーソル位置を軸にズーム
- ダブルクリックでその月に表示を合わせる
- `F` キーで全体表示、`T` キーで今日を中心に表示
- 起動時・取り込み直後は自動で全期間に合います。手を加えると窓の横に「全体」チップが出て、押すと自動表示に戻せます
- 行の高さも同様に自動調整されます。手動で変えると「自動」チップが出ます

## キーボード操作

| キー | 動作 |
|---|---|
| `Ctrl` / `⌘` + `Z` | 元に戻す |
| `Ctrl` / `⌘` + `Shift` + `Z`（Windowsは`Ctrl+Y`も可） | やり直す |
| `F` | 表示を全体に合わせる |
| `T` | 今日を中心に表示 |
| `Ctrl` / `⌘` + `K`、または `/` | 手帳を開く。予定名の一部で予定のカードへ、操作名で操作へ着けます。`Shift` + `Enter` はその語で絞り込み |
| `+` / `-` | タイムラインを拡大 / 縮小 |
| 一覧の行にフォーカス中 `Enter` | 予定カードを開く |
| 一覧の行にフォーカス中 `Delete` | 予定を削除（トーストから元に戻せます） |
| ガントにフォーカス中 `↑` / `↓` / `Home` / `End` | 予定を選ぶ |
| ガントで予定を選択中 `Enter` / `Delete` | 予定カードを開く / 予定を削除 |
| `Alt` + `←` / `→` | 選択中の予定を1日ずらす |
| 予定カードを開いている間 `←` / `→` | 前後の予定へ移る |
| `Esc` | 開いているカード・モーダルを閉じる、Presentモードを終了 |

## 予定の編集・削除

- 一覧の予定名・開始日・終了日は直接書き換えられます
- バーをクリック（タッチならタップ）するか、バー右端・一覧行の「•••」を押すと、その予定に沿って **予定カード** が開きます。名前・日付・カテゴリー・完了・メモをその場で直せます（変えた瞬間に保存）。スマホ幅では画面下のシートになります
- 予定カードの「‹ ›」で、閉じずに前後の予定へ移れます。「すべての項目」から、種類・個別色・締切表示・非表示・名前の位置などを含む詳細モーダルを開けます
- `Shift` + クリックで複数の予定を選ぶと、まとめてカードが開き、日付のずらし・カテゴリー・完了・削除を一括で行えます
- 詳細モーダルの「削除」、または一覧行での `Delete` キーで削除します。確認ダイアログは出ません。削除直後のトーストから「元に戻す」で戻せます
- タイムライン上のバーはドラッグで移動、端をドラッグで期間変更できます。ドラッグ中は移動後の日付が表示され、同じカテゴリーの締切マイルストーンを越えるときは警告が出ます
- ドラッグ後のトーストからも「元に戻す」で戻せます
- バーに名前が収まらないときは、バーの右に名前を出します（詳細モーダルの「名前の位置」で固定もできます）

## 取り込みできるJSON形式

外部AI（ChatGPTなど）から受け取る形式（`handoffVersion`）と、このアプリの完全バックアップ形式（`schemaVersion`）の2種類に対応します。

```json
{
  "handoffVersion": 1,
  "tasks": [
    {
      "name": "KV初稿提出",
      "start": "2026-07-08",
      "end": "2026-07-10",
      "categoryName": "制作",
      "note": "確認者：広報・営業",
      "milestone": false
    }
  ],
  "needsReview": []
}
```

- `end` を省略すると `start` と同じ日付として扱います
- `milestone: true` は期間のない単一日の予定です
- 日付が確定できない・カテゴリーが曖昧な項目は `needsReview` に入れると、取り込み後に「保留」として個別に確認・登録できます
- 未登録のカテゴリー名は自動で追加されます。カテゴリー色は、既存で使われていない色を優先して割り当てます
- 日付不正や必須項目の欠落は、反映前にエラーとして表示されます

ツールバーの「JSON」メニューから「文章→予定」を使うと、原文の文章をChatGPT向けの指示文に整形し、貼り付けやすい形でこの取り込み画面に戻せます。

取り込み画面で「予定をすべて入れ替え」を選んだときは、同じ名前の予定の完了・締切・色・名前の位置を引き継ぎます(バックアップ形式は項目を持っているので対象外)。反映後は、移動・追加・削除の件数がトーストと画面下の帯に出て、動いた予定には前の位置の点線と `+4日`、追加した予定には `新規` が残ります。帯の「変更だけ表示」で、動いた予定だけに絞って確認できます。✕・元に戻す・次の取り込みで消えます。

## AI連携用JSONの書き出し

「AI用JSON」ボタンで、現在のプロジェクト全体をChatGPTなどに渡しやすい形式でコピーできます。取り込み形式と対になる `returnContract` を含み、外部AIに変更を依頼してそのまま取り込み直す運用ができます。

## データについて

予定はこのブラウザの端末にだけ保存されます（IndexedDB、対応していない環境では`localStorage`）。別の端末や別ブラウザへの同期は行いません。ブラウザデータを削除すると消えるため、節目ごとに「書き出し・復元」から完全バックアップJSONを保存してください。

複数タブを同時に開いた場合、片方の保存内容ともう片方が食い違うと、保存を止めて確認を求めます。

## GitHub Pagesでの公開

1. このリポジトリの **Settings** → **Pages** を開く
2. **Build and deployment** の Source を **GitHub Actions** に設定
3. `main` ブランチへpushすると、`.github/workflows/deploy-pages.yml` が公開を実行します

公開後のURLは通常、`https://silovar-uk.github.io/gantt/` です。
